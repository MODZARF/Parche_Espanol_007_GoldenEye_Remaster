# Parche_Español_007_GoldenEye_Remaster (Xbox360)
Parche no oficial que traduce los textos de GoldenEye 007 Remastered (Xbox 360) al español mediante diferencia hexadecimal.


Este parche no contiene archivos del juego. Solo aplica cambios por diferencia hexadecimal (.ZARF) sobre tu copia original.

### Cómo funciona
El parcheador busca los offsets exactos de los textos en base a un archivo con extensión .ZARF y reemplaza los bytes en hexadecimal, manteniendo el tamaño y estructura original del juego para evitar errores.

### Uso
1. Ejecuta el `Parche_007.exe`
2. Selecciona la carpeta raíz del juego
3. Listo

Creado por ZARF
